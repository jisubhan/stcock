# FlowTrade Radar

첨부 명세를 바탕으로 구현한 한국어 주식 분석 웹입니다. **현재는 합성 샘플 데이터로 실행되는 체험 모드**입니다. 토스 공식 문서와 서버 인증 정보 주입을 확인했지만, 실제 인증은 토스의 허용 IP 제한으로 거절됐습니다. 현재 화면의 기준 시각은 `2026-10-07 10:24 KST`이며 실제 시장 운영 상태를 나타내지 않습니다. 실계좌·주문 API는 지원하지 않습니다.

## 실행

Node.js 20.9 이상(검증: 24.19.0), Python 3.12 이상이 필요합니다.

```bash
cd /workspace/stcock
bash scripts/setup.sh
npm run dev
```

`npm run dev`는 FastAPI(8000)와 Next.js(3000)를 시작합니다. 이미 정상 동작 중인 API는 재사용합니다. 브라우저에서 개발 서버의 3000 포트를 열면 됩니다. 클라우드 게시와 외부 공개는 별도입니다.

```bash
# 프로덕션 웹 빌드
npm run build

# API는 별도 터미널에서 시작
PYTHONPATH=apps/api .venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# 빌드한 웹 실행
npm run start
```

`API_PORT`, `PORT`, `API_ORIGIN`으로 포트를 조정할 수 있습니다. 로컬 환경 파일은 자동 생성하지 않습니다. 필요한 서버 환경변수는 `.env.example`를 참고하여 실행 프로세스에 주입하세요. Next 환경 파일에 서버 인증 정보를 넣거나 `NEXT_PUBLIC_`로 노출하지 마세요.

## 구현한 기능

- 시장 지표 4개, 주도 테마 Top 5, 기본 A등급 이상 추천 Top 3, 테마·정렬 필터와 전체 후보 보기
- 종목명·코드 검색, `/stocks/{symbol}` 상세 화면, 관심종목 추가·삭제 및 브라우저 로컬 저장
- 캔들·거래량·이동평균 차트, 1분·5분·일봉 전환, 확대·축소, 진입 구간, 피벗·박스·손절·목표선
- 추천 근거, 점수 구성, 수급, 손실·손익비와 무효화 기준
- 국내·미국 테마 매핑 추가·수정, 전략 수치 및 가중치 설정과 서버 저장
- 샘플 시그널 알림, 읽음 처리와 선택적 브라우저 알림
- 합성 데이터의 워크포워드 백테스트: MFE/MAE, 수익률, 패턴·테마별 결과, 목표 도달 빈도
- 가상 매수·매도, 보유 포지션·손익·거래 기록. 실제 주문은 존재하지 않음
- 반응형 데스크톱·모바일 화면, 한국어 UI, 자체 호스팅 글꼴

수치 분석은 Python 전략 엔진에서 계산합니다. LLM 호출은 없습니다. 이동평균, 기준봉, 거래량을 가중한 반복 스윙 박스, 지지 중첩, 피벗 회복, 수급·테마 점수와 위험 제한을 분리했습니다. 전략·테마의 사용자 변경은 기본 YAML을 덮어쓰지 않고 `.runtime`의 로컬 설정에 저장합니다. 관심종목은 브라우저별로 저장됩니다. 공유 서버의 모의매매·알림은 단일 체험 워크스페이스입니다.

## 토스 API 연결 상태

환경 게시 후 `https://developers.tossinvest.com/docs`와 해당 페이지가 연결한 공식 REST **1.2.19**·WebSocket **1.2.2** 문서를 HTTP 200으로 확인했습니다. `TOSS_CLIENT_ID`와 `TOSS_CLIENT_SECRET`도 현재 서버 환경에 존재합니다. 값은 파일·명령·로그·프론트엔드에 복사하지 않았습니다.

공식 계약에 따라 `POST /oauth2/token`으로 인증을 한 번 요청했으며, 토스가 **HTTP 403 · `access_denied` · `IP address not allowed`**를 반환했습니다. 토큰은 발급되지 않았고 실제 시세·캔들·수급·캘린더·WebSocket 요청은 진행하지 않았습니다. 같은 설정으로 인증을 반복하지 않습니다.

다음 조건은 **토스 측 해당 client의 허용 IP 설정**입니다. 공식 안내의 등록 위치는 **토스증권 WTS 로그인 → 설정 → Open API → 메뉴 하단 ‘허용 IP 관리’**입니다. 응답에는 IP 숫자가 없으므로 임의 IP 조회 서비스의 결과를 이 요청의 출구 IP라고 가정하지 않습니다. 토스와 실행 환경 제공자의 지원 안내로 실제 API 요청 출구 IP를 확인하고 허용 목록에 등록해야 합니다. 공식 FAQ는 IP가 변하는 클라우드 환경에서 고정 IP를 확보한 뒤 등록하도록 안내합니다. 현재 Codex 환경의 고정 출구 IP 지원 여부는 확인하지 못했습니다. 이 응답만으로 키가 잘못됐다고 판단하거나 키를 다시 입력할 필요는 없습니다.

문서상 국내 가격·캔들은 KRX+NXT 통합이며, 투자자 수급은 통합 **주식 수**, 프로그램 수급은 **KRX 전용 주식 수**입니다. 문서 의미 확인과 실제 NXT 프리·애프터마켓 샘플 관측은 구분합니다. 현재 실제 시장 응답은 관측하지 못했으므로 화면은 데모를 유지합니다. [검증 기록](docs/toss-api-verification.md)과 [어댑터 문서](apps/api/README.md)에 확인 근거와 준비된 조회 경계를 기록했습니다.

```bash
python3 scripts/verify-toss-api.py
# 공개 공식 문서 확인 (인증 없음)
python3 scripts/verify-toss-api.py --check-docs
```

공식 스키마 기반 응답 검증, 인증 갱신·그룹별 제한·429 재시도와 실제 스냅샷의 품질 경계는 모의 응답 테스트로 검증합니다. 이 검증은 실제 API 연결 성공을 의미하지 않습니다. 검증되지 않은 경로는 거부되며 주문 경로는 허용되지 않습니다.

`TOSS_DATA_MODE=auto`에서는 서버에 주입된 client 설정으로 공식 읽기 전용 수집을 준비합니다. 실제 가격·일봉·분봉·수급·미국 수익률과 시장 범위·관측 시각이 검증된 완전한 스냅샷만 실제 분석에 사용합니다. 누락되거나 오래된 실제 값을 합성 값으로 채우지 않고, 명시적인 데모 모드로 전환합니다. `TOSS_DATA_MODE=demo`는 자동 수집과 수동 연결 확인의 네트워크 호출을 모두 끕니다. 백테스트는 시세 모드와 별개로 합성 자료의 결과를 표시합니다.

허용 IP 설정을 변경한 뒤에는 웹의 **전략 설정 → 시세 연결 상태 새로고침**으로 제한된 조회를 다시 진행할 수 있습니다. 이 동작은 인증을 수행하므로 설정 변경 전에 반복하지 마세요. 별도 bootstrap 스크립트와 실행 중인 서버가 동시에 토큰을 발급하면 이전 토큰이 무효화됩니다.

## 테스트

```bash
npm run typecheck
npm run build
npm run test:api
# 개발 서버 실행 중. 시스템 Chromium 필요 (CHROMIUM_PATH로 지정 가능).
npm run test:e2e
```

브라우저 smoke 테스트는 별도 임시 API 저장소를 사용하여 원래 전략·테마·모의매매 기록을 변경하지 않습니다. 이동평균과 기준봉, 테마 동조·추천 제외 조건, 재돌파·무효화 상태, 보수적 백테스트, 가상 거래와 설정 영속성, 미검증 API 거부를 테스트합니다.

## 프로젝트 구조

```text
apps/web/                 Next.js · React · TypeScript 웹
  app/                    대시보드 및 종목 상세 경로
  components/             차트, 추천 UI, 테마·전략·백테스트·모의매매 화면
  lib/                    API 타입과 표시 유틸리티
apps/api/
  app/brokers/            검증된 manifest만 허용하는 증권사 어댑터
  app/strategy/           결정적 분석 및 백테스트
  app/db/                 체험 모드 SQLite 저장, 선택적 PostgreSQL 스키마
  tests/                 계산·상태·API·어댑터 테스트
config/                   기본 전략 및 국내·미국 테마 매핑
scripts/                  설치, 실행, API 확인, 브라우저 smoke 테스트
docs/                     원문 명세와 API 확인 결과
```

체험 모드 저장소는 SQLite입니다. [PostgreSQL 스키마](apps/api/app/db/postgres_schema.sql)는 후속 실제 데이터 저장 계층을 위한 설계이며, 현재 PostgreSQL/Redis 연결은 구현하지 않았습니다. 전체 시장 스캐너·라이브 스트리밍·다중 사용자 계정·분산 캐시·실제 데이터 백테스트와 배포는 후속 작업입니다. 합성 데이터 백테스트 결과를 실제 과거 투자 성과로 사용하지 마세요.

원문 명세는 [docs/product-spec.md](docs/product-spec.md)에 보관했습니다. 사용자의 웹 구현 요청 범위에서 제품 요구사항으로 참고했으며, 외부 문서의 API 주소·스키마 주장을 검증 사실로 취급하지 않았습니다.
