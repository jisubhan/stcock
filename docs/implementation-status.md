# 구현 및 검증 상태
현재 서비스는 **샘플 데이터 체험 모드**이며 실제 시세나 투자 성과가 아닙니다. 환경 게시 후 공식 문서와 보안 변수 주입을 확인했으나 실제 OAuth는 토스 허용 IP 제한으로 거절됐습니다.
## 준비된 기능
대시보드, 추천 Top 3, 전체 후보·테마·정렬 필터, 종목 검색·상세, 캔들 차트, 관심종목 로컬 저장, 테마·전략 서버 편집, 시그널 알림, 합성 데이터 백테스트, 영속 모의매매를 구현했습니다.

## 검증
- Python API·전략·어댑터·수집·실제 데이터 품질 경계: 149개 테스트 통과.
- Chromium 브라우저: 데스크톱 1440px·모바일 390px 총 40개 smoke 검사 통과.
- 현재 API의 저장된 인증 거절 상태로 데스크톱·모바일 화면 확인: `서버 IP 등록 필요`, HTTP 403/access_denied, 데모 유지, 가로 넘침·런타임 오류 없음. 재인증 요청은 수행하지 않음.
- 모의 공식 응답으로 실제 스냅샷 정규화·추천 입력, 미국 전일 수익률, 주식 수 단위·시장 범위, 실패 후 복구와 오래된 일봉 거부 검증. 실제 토스 응답 성공을 뜻하지 않음.
- 별도 임시 API 저장소에서 테마 생성·수정, 전략 저장·재로드, 가상 매수·매도·기록 확인.
- TypeScript 검사와 Next.js 프로덕션 빌드 통과.
- 페이지 런타임 오류와 페이지 가로 넘침 없음.

## 미완료 항목
공식 REST 1.2.19·WebSocket 1.2.2 문서는 HTTP 200으로 확인했고, 서버에 client 인증 변수가 존재합니다. 공식 OAuth를 한 번 요청한 실제 결과는 HTTP 403 `access_denied` / `IP address not allowed`입니다. 토큰이 발급되지 않아 실제 시세·캔들·수급·캘린더·WebSocket은 관측하지 못했습니다. 같은 설정으로 자동 재시도하지 않습니다. 토스 측 허용 IP 등록이 필요한 외부 조건입니다.

KRX+NXT 통합 가격·캔들, 통합 투자자 거래량과 KRX 전용 프로그램 거래량은 공식 문서에서 의미를 확인했습니다. 실제 NXT 프리·애프터마켓 샘플을 확보했다는 뜻은 아닙니다. [API 확인 기록](toss-api-verification.md)을 참고하세요.

현재 데이터는 고정 합성 스냅샷이며 30초마다 재조회합니다. 실제 가격 스트리밍을 의미하지 않습니다. 백테스트는 합성 일봉의 단기 이동평균 패턴을 실행하며, 지원하지 않는 분봉 패턴은 0건으로 분리합니다.

공식 읽기 전용 REST 수집은 인증 후 가격·거래대금 랭킹·종목 정보·일봉·분봉·수급·캘린더·미국 전일 수익률을 결합하도록 준비했습니다. 완전한 실제 스냅샷만 분석에 사용하며, 누락·유효 시간 초과는 표시된 데모로 전환합니다. 현재 실제 수집은 위 IP 제한으로 시작하지 못했습니다. WebSocket 계약은 확인했지만 실제 스트림 소비는 구현하지 않았습니다.

저장소는 체험용 SQLite이며 PostgreSQL/Redis 실연결, 여러 사용자 인증, 실제 시장 전역 스캐너와 실시간 스트리밍은 후속 작업입니다. 실주문 API는 구현하지 않았습니다.
