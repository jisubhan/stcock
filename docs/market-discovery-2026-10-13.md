# 전체 시장 탐색 · 수급 기대 테마 · 종목 차트

기존 FlowTrade Radar를 직접 확장했다. 기존 일봉 전략·모의매매·v1.2 개장 순환과 5분봉 builder를 유지하며 실제 자료만 사용하는 별도 discovery 경로를 추가했다. 실계좌와 주문 호출은 없다.

## 화면과 데이터 흐름

1. 전체 종목 목록에서 KOSPI/KOSDAQ/KR_ETC의 ACTIVE 보통주 STOCK을 확인한다. ETF·ETN·우선주·상장폐지 상품은 기본 범위에 포함하지 않는다. 목록은 Toss의 거래 가능 목록이며 거래소 전체 상장 명부와 동일하다고 주장하지 않는다.
2. 공식 업종 계층·구성 종목을 수집해 새 종목을 `OFFICIAL_SECTOR_MEMBER`로 연결한다. 대·중·소 분류를 보존하며 한 종목의 여러 업종 소속을 함께 표시한다. 분류 삭제·구성 변경은 과거 버전을 유지하고 현재 연결에서는 제외한다.
3. 미국/국내 업종 관측과 실제 종목 자료로 수급 기대 테마를 정리한다. 부모·자식 및 구성 종목이 크게 겹치는 그룹을 Top3에서 중복 억제한다. 국내 구성 종목이 아직 확인되지 않은 미국 업종은 연결 대기이며 국내 추천으로 승격하지 않는다.
4. 테마별 종목은 테마 우선순위·실제 가격 상태·실제 차트 구조·구간 거래대금 자료로 WATCH 점수를 계산한다. 추천 종목 또는 목록의 종목을 선택하면 실제 일봉·5분봉·1분봉과 MA5·박스·중요 봉·지지/저항·이전 종가·구조적 손절을 확인한다. 없거나 일부만 수신한 자료는 대기·부분 상태다.

테마 우선순위는 미국 1일 15점·1주 10점, 국내 업종 성과 20점·참여 폭 20점·실제 구간 거래대금 속도 15점, 차트 구조 10점·확인된 재료 10점이다. 누락된 항목은 null이고 분모 및 근거 확보율을 따로 표시한다. 종목은 테마 30점·가격 상태 20점·차트 구조 30점·관측 구간 거래대금 20점이다. 결측을 안전한 0으로 대체하거나 점수를 수익 확률로 표시하지 않는다.

## 갱신과 인증

전체 가격은 최대 100개씩 기본 2초 주기로 순환한다. 실제 한 바퀴 시간은 대상 수·HTTP 응답·rate limit에 따라 달라지며 완료했다고 모든 가격이 LIVE가 되는 것은 아니다. 15초 이내 공급자 timestamp와 공식 활성 세션을 확인한 가격만 LIVE다. 장 종료 마지막 가격은 STALE다.

기존 5초 수집기는 선택·주도·뉴스 종목을 빠르게 조회하고 discovery 저장소에도 동일 실제 수신을 반영한다. 가격 모니터의 200개 분모는 전체 시장 분모와 분리된다. 차트 조회는 한 주기 최대 2개 종목이며 선택 종목을 우선하고 캐시를 약 60초간 재사용한다. 화면은 전체 목록/테마를 30초, 선택 종목 분석 캐시를 5초마다 확인한다.

종목 목록·분류는 일일 캐시, 미국/국내 업종 관측과 장전 가설은 약 60초 주기로 갱신한다. 브라우저가 없어도 worker가 갱신하며 개장 후 장전 가설을 보존한다. 별도 API 권한 부족은 해당 기능의 UNAVAILABLE로 표시한다. 일시적 제한은 백오프 후 재시도하며 기존 정상 가격 인증을 새 endpoint의 일반 403/404로 무효화하지 않는다.

수집기는 기존 서버의 단일 Toss HTTP/OAuth client를 공유한다. 읽기 API를 열거나 차트 선택을 한다고 OAuth를 다시 발급하지 않는다. 실제 샘플 재검증 동안 모든 수집기가 공유 client의 검증 호출 한도를 침범하지 않도록 대기한다. 비밀키·토큰은 DB와 웹 응답에 저장하지 않는다.

## 측정과 신뢰도

- 전시장 주식 랭킹의 최대 100개 당일 누적 거래대금으로 **관측 거래대금 테마**를 별도 계산한다. 원본 거래대금과 다중 소속에 따른 배분 값을 함께 보존한다. 분모는 실제 관측한 고유 종목이며 전체 시장 거래대금 점유율이 아니다.
- 업종 성과·구성 목록에는 공급자 기준시각 계약이 없다. 수신시각을 시장 시각으로 바꾸지 않고 `ANALYSIS_ONLY`로 유지한다. 실제 거래대금도 구간 차분 없이는 속도가 아니며 투자자 순매수로 해석하지 않는다.
- 뉴스/DART/공식 발표는 기존 소스 설정이 없으면 미연결이다. 공식 업종 연결만으로 뉴스 수혜 또는 정책 수혜를 추론하지 않는다. 확인된 원문과 기업 관계가 있어야 재료 가점을 줄 수 있다.
- 미국 업종 관측은 공급자 기준시각 미제공으로 미국 확정 종가 성과라고 단정하지 않는다. 공식 달력의 세션과 성과의 시각 검증을 구분한다.
- 기존 EARLY_ENTRY 엔진을 재사용한다. 완성 봉·실제 유동성·테마 확인·스프레드·VI·정지 등의 위험 조건이 없으면 WATCH 상태로 남으며 차트 READY가 매수 진입 확정은 아니다.
- 종목 목록이 아직 없고 랭킹으로만 확인한 종목은 초기 관측으로 표시한다. 목록 분모를 늘리지 않는다. 미분류 강세 종목은 별도 표시하고 연결 대기로 남긴다.
- 새 자료가 과거 조회에 섞이지 않도록 최초 수신·변경 버전을 저장한다. 미래 시세·통계·분류·뉴스·캔들은 제외하고 충돌한 한 응답의 중복 시세를 임의 선택하지 않는다.

## DB와 API

`003_discovery.sql`은 버전별 원본 record, 최신 cache, 분석 작업 queue를 추가한다. 기존 로컬 DB를 `.runtime/backups/radar-before-market-discovery-2026-10-13.sqlite3`로 SQLite 백업한 뒤 적용했다. 시작 및 migration은 반복 적용이 가능하며 이전 거래·알림·백테스트는 유지한다. rollback은 worker를 정지하고 백업 후 003 → 002 → 001 순서다.

- `GET /api/discovery/overview`: 목록 범위, 시세/분류 관측률, 예상 테마, 관측 거래대금 테마, 일일 업종 성과, 미분류 강세, 기능별 상태.
- `GET /api/discovery/stocks?page=1&limit=25&q=...&theme_id=sector:...&unclassified=true`: 검색·페이지·분류 및 누적 거래대금의 개별 상태.
- `GET /api/discovery/stocks/{symbol}?theme_id=sector:...`: 실제 캐시 분석 및 필요한 캔들의 백그라운드 조회 요청. 영문 포함 국내 6자리 코드도 지원한다.

새 API는 합성 fallback을 제공하지 않는다. 최신 조회는 전체 가격 이력을 순회하지 않고 cache를 읽는다. 영속 자료는 SQLite에 누적되며 전체 시장 시세 변경 이력의 보존 기간/압축 정책, 대용량 저장 용량은 후속 운영 설정이 필요하다. Railway에서 영속 Volume이 없으면 컨테이너 재배포 때 이력과 cache를 잃을 수 있다.

## 검증 범위

공식 문서의 읽기 경로 5개와 schema 10개를 추가했고 이전 계약을 유지했다. API·순환 스캔·공유 client·분류 변경·과거 시점·실제 형태 차트·미래/가짜 자료 거부를 offline constructed transport로 검증한다. 검색·미등록 영문 코드·130개 이상 페이지 이동·차트 대기→수신·초기 랭킹 분모·개장 전 자동 가설과 개장 후 보존·기존 UI 회귀를 포함한다.

브라우저 구성 자료와 offline 테스트는 실제 시장 수집이나 투자 성과의 증거가 아니다. 실제 새 endpoint의 Railway 권한·수신 종목 수와 기준시각은 배포 후 원격 응답을 별도로 확인한다. 테스트 및 그 실제 확인 결과는 작업 완료 응답에 보고한다.

완료한 로컬 검증: 전체 API pytest **760개 통과**, TypeScript 검사 및 production build 통과, 기존 브라우저 검사 **58개**와 새 탐색 검사 **26개** 통과. Desktop 1440px/Mobile 390px에서 예상 테마와 관측 거래대금 분리, 테마→미등록 종목→차트 대기→실제 형태 캔들, 결측 가격선, 검색/미분류/100개 초과 페이지, 실패·오래된 시세·합성 출처 거부를 확인했다. 기존 Starlette deprecation warning 1개가 있다.

새 화면의 구성 자료 기반 기록은 `/tmp/flowtrade-discovery-e2e/report.json`, 기존 회귀 이미지는 `/tmp/flowtrade-market-discovery-regression/`이다. 이 로컬 파일은 실제 시장 관측 결과가 아니다.
